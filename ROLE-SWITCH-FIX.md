# 🔧 Исправление проблемы с переключением ролей

## Проблема
Переключение ролей после входа не работает из-за ошибок в Supabase подключении.

## Причины
1. **Supabase не подключен** - переменные окружения не настроены
2. **Ошибки в API сервисе** - функции выбрасывают исключения
3. **Отсутствие обработки ошибок** - приложение падает при ошибках

## Решение

### 1. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_GEMINI_API_KEY=your_gemini_api_key
```

### 2. Исправления в коде

#### AuthContext.tsx
- Добавлена обработка ошибок в `login()` и `switchRole()`
- Функции продолжают работу даже при ошибках Supabase
- Улучшена очистка имени пользователя при смене роли

#### apiService.ts
- Добавлен fallback для `ensureManufacturerFacility()`
- Возвращает mock данные когда Supabase недоступен

### 3. Проверка работы

#### Локальная проверка:
1. Откройте консоль браузера (F12)
2. Войдите в систему
3. Попробуйте переключить роль
4. Проверьте, нет ли ошибок в консоли

#### Проверка Supabase:
1. Убедитесь, что Supabase проект создан
2. Проверьте, что SQL скрипт выполнен
3. Убедитесь, что переменные окружения правильные

## Тестирование

### Без Supabase (локально):
- Переключение ролей должно работать
- В консоли будут предупреждения о недоступности Supabase
- Приложение не должно падать

### С Supabase:
- Переключение ролей работает полностью
- Создаются производственные мощности для производителей
- Нет ошибок в консоли

## Отладка

### Если переключение все еще не работает:

1. **Проверьте консоль браузера**:
   ```javascript
   // Должны быть предупреждения, но не ошибки
   console.warn("Supabase not connected, returning mock facility");
   ```

2. **Проверьте localStorage**:
   ```javascript
   // В консоли браузера
   console.log(JSON.parse(localStorage.getItem('currentUser')));
   ```

3. **Проверьте переменные окружения**:
   ```javascript
   // В консоли браузера
   console.log(import.meta.env.VITE_SUPABASE_URL);
   console.log(import.meta.env.VITE_SUPABASE_ANON_KEY);
   ```

## Альтернативное решение

Если проблема остается, можно временно отключить Supabase:

```typescript
// В services/supabaseClient.ts
export const supabase = null; // Временно отключить
```

Это позволит приложению работать в режиме mock данных.

## Готово!

После применения этих исправлений переключение ролей должно работать корректно.
